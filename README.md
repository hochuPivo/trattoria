# Trattoria Restobar — Промо-сайт рестобара

Официальный репозиторий проекта промо-сайта рестобара «Trattoria». Проект разработан на базе чистой вёрстки с интеграцией в CMS WordPress, а также опубликован в виде интерактивного прототипа на GitHub Pages.

## 🛠 Стек технологий
* **Фронтенд:** HTML5, Modular CSS3 (BEM-нейминг, CSS Variables), Vanilla JS (ES6+)
* **Бэкенд / CMS:** WordPress (PHP 8.3, MySQL 8.0), кастомная тема `trattoria-theme`
* **Серверная часть:** Ubuntu 24.04 LTS, Nginx, PHP-FPM, UFW Firewall
* **Типографика:** Bickham Script One, Cormorant Garamond, Roboto, Inter
